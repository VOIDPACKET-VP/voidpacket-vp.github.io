## What it is

A single hub page hosting small games I build in my spare time, compiled to WebAssembly so they run directly in the browser — no installs, no App Store review.

## Stack

- **C++** and **Raylib** for game logic and rendering
- Compiled to **WebAssembly** via Emscripten
- Lightweight static hub page for browsing and launching games

## Status

Two small games shipped so far; a third (a physics-based puzzle game) is in progress.
