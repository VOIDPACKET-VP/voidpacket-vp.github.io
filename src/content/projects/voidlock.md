## What it is

Voidlock is a fitness app with a twist: skip your workout, lose real money. Users stake a deposit up front, and missed sessions get forfeited to a charity pool.

## Stack

- **Next.js** frontend with server components for the dashboard
- **NestJS** API handling stake logic and workout verification
- **Supabase** for auth, Postgres, and storage

## Status

Actively in development — currently building out the wearable-device integration for automatic workout verification.
